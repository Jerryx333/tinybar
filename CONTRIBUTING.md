# Contributing

This repository is in the planning stage. Discuss a specific failure mode or small prototype before adding broad features.

- Run `bash scripts/check.sh` for documentation changes.
- Mark proposals and unverified OS behavior clearly. Do not claim support without real-machine evidence.
- Avoid collecting private app inventories, screenshots or credentials.
- Never silently replace another menu-bar manager, alter its settings or enable startup.
- Future code contributions must retain third-party attribution and prioritize recoverability, bounded work and low resource use.

Use Conventional Commit subjects. Keep generated binaries, local reports and environment notes outside Git.
