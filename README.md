# TinyBar

[中文](README.md) | [English](README.en.md)

准备做一个轻量、可靠的 macOS 菜单栏管理器：不常用的图标收起来，需要时点一下展开。

## 为什么做它

菜单栏空间有限，尤其在刘海屏和多显示器切换时。图标管理器自身失去响应或无法读取项目时，隐藏的软件也可能难以找到。TinyBar 希望把“能展开、能找回、少占资源”放在首位。

## 当前状态

**项目筹备中，尚无可运行应用、安装包或已验证的兼容性声明。** 本仓库目前公开产品范围、技术验证计划和贡献入口；不是已完成的 Ice 替代品。

这是独立实现计划，不是 Ice 的分支，也不包含 Ice 代码。开发中如复用任何第三方代码，将保留相应许可证和来源。

## 首版范围

- 一个菜单栏入口，点击展开/收起隐藏项目。
- 常显与隐藏两组，记住用户安排；尽量使用系统已有的 Command 拖动。
- 多显示器、分辨率变化、睡眠唤醒后，入口保持可达。
- 退出或功能失效时优先恢复项目可见，提供明确恢复路径。
- 原生实现，以事件驱动为先；避免常驻扫描、截图缓存和不必要的权限。

以上均为计划，需逐项验证。首版不做额外图标浮动栏、主题美化、搜索或复杂自动化。详细取舍见[产品范围](docs/scope.md)。

## 如何参与

现在可以阅读[验证计划](docs/roadmap.md)，通过 Issues 提供复现步骤或讨论最小功能。请注明 macOS 版本、芯片、屏幕数量和具体行为，避免上传完整菜单栏截图或私人应用清单。

仓库文档检查：`bash scripts/check.sh`。应用构建命令将在首个原型可运行后提供，不需要现在退出或卸载现有菜单栏管理器。

姊妹项目：[TinyStat](https://github.com/Jerryx333/tinystat)，轻量 CPU/GPU/内存温度监控。
